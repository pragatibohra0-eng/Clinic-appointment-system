# Clinic Appointment System

A **Java-based Clinic Appointment Management System** designed to manage patients, doctors, appointments, billing, and basic clinic reports through a command-line interface.

This project was developed as an academic Java project to demonstrate practical implementation of **Object-Oriented Programming, Collections, Interfaces, Exception Handling, Java Streams, Multithreading, JDBC, and File Handling**.

---

## Overview

The Clinic Appointment System provides a simple way to manage common clinic operations from a single command-line application.

The system allows the user to:

* Register patients
* View registered patients
* View doctors
* Book appointments
* View scheduled appointments
* Cancel appointments
* Generate patient bills
* Calculate total clinic revenue
* Export appointment information as a CSV report
* Store patient information using JDBC

The application follows a modular package structure that separates models, services, database operations, and the main application.

## Java Concepts Demonstrated

This project demonstrates several concepts from the Java programming syllabus.

### 1. Object-Oriented Programming

The application is divided into multiple classes representing real-world entities such as:

* Patient
* Doctor
* Appointment
* Clinic

This provides a clear object-oriented structure.

### 2. Encapsulation

Class data is managed through appropriate fields and methods rather than exposing implementation details directly.

### 3. Inheritance

Common functionality can be reused through class relationships where applicable.

### 4. Abstraction

The project separates the interface of operations from their implementation.

### 5. Interfaces

The project includes a `Payable` interface for operations related to billing/payment.

### 6. Builder Pattern

The `Patient.Builder` implementation is used to construct patient objects in a structured way.

Example:

```java
Patient p = new Patient.Builder()
        .name(name)
        .age(age)
        .contact(contact)
        .bloodGroup(bg)
        .build();
```

### 7. Exception Handling

The application handles errors during operations such as appointment booking, report generation, and invalid operations.

### 8. Java Streams

Appointments can be processed and sorted using Java Streams.

```java
clinic.getAppointments().stream()
        .sorted(Comparator.comparing(a -> a.getSlot()))
        .forEach(System.out::println);
```

### 9. Multithreading

Appointment booking is performed using `ExecutorService`, allowing the booking operation to execute through a worker thread.

### 10. JDBC

The database layer provides JDBC-based persistence for patient information.

## Getting Started

### Prerequisites

Install the following before running the project:

* **Java JDK 17 or later**
* **Visual Studio Code**, IntelliJ IDEA, or another Java IDE
* A JDBC-compatible database if database persistence is enabled
* Required JDBC driver

Verify Java installation:

```bash
java -version
```

Verify the Java compiler:

```bash
javac -version
```

---

## Clone the Repository

```bash
git clone https://github.com/pragatibohra0-eng/Clinic-appointment-system.git
```

Navigate into the project:

```bash
cd Clinic-appointment-system
```

## Running the Application

### Using VS Code

1. Open the cloned project folder in VS Code.
2. Make sure the Java Extension Pack is installed.
3. Open:

```text
src/com/clinic/Main.java
```

4. Run `Main.java`.
5. Use the command-line menu to interact with the application.

## Database Configuration

The project contains a dedicated database layer:

```text
src/com/clinic/db/Database.java
```

The database class is responsible for JDBC-based database operations.

Before running database-dependent functionality:

1. Install and start the required database server.
2. Create the required database.
3. Configure the JDBC connection details in `Database.java`.
4. Ensure the required JDBC driver is available in the project classpath.

> Database credentials should not be committed to GitHub. Use local configuration or environment variables for sensitive information.

## Booking an Appointment

The appointment booking process follows these steps:

```text
1. Display doctors
        ↓
2. Enter Doctor ID
        ↓
3. Enter Patient ID
        ↓
4. Enter appointment date and time
        ↓
5. Submit booking
        ↓
6. Appointment processed asynchronously
        ↓
7. Appointment ID generated
```

The expected date/time format is:

```text
dd-MM-yyyy HH:mm
```

Example:

```text
18-09-2026 14:30
```
